# 🥩 Churrascômetro & Rateio Pix

Calculadora inteligente para organizar churrascos, dividir despesas de forma proporcional e gerar cobranças via Pix na hora.

## ✨ Funcionalidades
- **Rateio Proporcional:** Separa automaticamente o valor de quem **Só Come** de quem consome **Comida + Bebida**.
- **Lista Dinâmica de Participantes:** Adicione convidados, altere a categoria de consumo em tempo real e marque quem já pagou.
- **Balanço Financeiro:** Acompanhe o total arrecadado e quanto ainda falta receber.
- **QR Code Pix Oficial (BR Code):** Gera o QR Code e o código *Pix Copia e Cola* prontos para qualquer banco.
- **Compartilhamento Rápido:** Formata o resumo completo com a lista de presença e status de pagamento direto para o grupo do WhatsApp.

## 💻 Tecnologias e Versões no Repositório
- **Versão Web / PWA (`index.html` + `manifest.json`):** Aplicativo web responsivo com suporte para empacotamento Android (APK).
- **Versão Desktop (`app.py`):** Aplicação em Python construída com **Streamlit** e `qrcode`.
